## 📋 About

This was my first portfolio project, which I prepared in a hurry. The interface wasn't great, but it served its purpose. I created it to showcase my projects, the technologies I use, and information about myself in a nice way.

## ✨ Features <a id="features"></a>

- **Fully Responsive Design:** A seamless user experience optimized for mobile, tablet, and desktop devices.
- **Dynamic Theme System:** Various color theme options that users can choose according to their preferences.
- **Fluid Animations:** Modern transitions and micro-interactions enhanced with the Framer Motion library.
- **Project Gallery:** An interactive modal system where projects are displayed with videos, screenshots, and detailed descriptions.

## 🛠️ Technologies <a id="technologies"></a>

- **React 19**: Fast and modern interface development with the latest React features.
- **Vite**: Fast development and high-performance build tool.
- **Tailwind CSS**: Modern, flexible, and customizable styling system.
- **Framer Motion**: Creating fluid animations and interactive user experiences.
- **Lucide Icons**: Modern and simple icons for the interface.

## 🚀 Installation <a id="installation"></a>

To run the project in your local environment, you can follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/xkintaro/first-portfolio-2024.git
   cd first-portfolio-2024
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   You can view the project by going to `http://localhost:5173` in your browser.
