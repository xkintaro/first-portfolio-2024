## 📋 Hakkında

Aceleyle hazırladığım ilk portfolyo projemdi. Arayüzü çok iyi sayılmazdı ama amacını yerine getiriyordu. Projelerimi, kullandığım teknolojileri ve hakkımdaki bilgileri güzel bir şekilde sergilemek için oluşturmuştum.

## ✨ Özellikler <a id="features"></a>

- **Tam Duyarlı Tasarım:** Mobil, tablet ve masaüstü cihazlar için optimize edilmiş kusursuz kullanıcı deneyimi.
- **Dinamik Tema Sistemi:** Kullanıcıların tercihlerine göre değiştirebileceği çeşitli renk tema seçenekleri.
- **Akıcı Animasyonlar:** Framer Motion kütüphanesi ile zenginleştirilmiş modern geçişler ve mikro etkileşimler.
- **Proje Galerisi:** Projelerin videolar, ekran görüntüleri ve detaylı açıklamalarla sergilendiği etkileşimli modal sistemi.

## 🛠️ Teknolojiler <a id="technologies"></a>

- **React 19**: En güncel React özellikleriyle hızlı ve modern arayüz geliştirme.
- **Vite**: Hızlı geliştirme ve yüksek performanslı build aracı.
- **Tailwind CSS**: Modern, esnek ve özelleştirilebilir stil sistemi.
- **Framer Motion**: Akıcı animasyonlar ve etkileşimli kullanıcı deneyimi oluşturma.
- **Lucide Icons**: Arayüz için modern ve sade ikonlar.

## 🚀 Kurulum <a id="installation"></a>

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları takip edebilirsiniz:

1. **Depoyu klonlayın:**
   ```bash
   git clone https://github.com/xkintaro/first-portfolio-2024.git
   cd first-portfolio-2024
   ```

2. **Bağımlılıkları yükleyin:**
   ```bash
   npm install
   ```

3. **Geliştirme sunucusunu başlatın:**
   ```bash
   npm run dev
   ```
   Tarayıcınızda `http://localhost:5173` adresine giderek projeyi görüntüleyebilirsiniz.
